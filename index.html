Landing page con chatbot integrado en n8n

Automatización para CVs, consultas y promomails

Este proyecto demuestra una integración pública entre una página web, formularios n8n, un agente conversacional y servicios de Google para registrar datos y enviar información automáticamente.

Qué automatiza el proyecto

Los flujos están separados para que cada parte pueda probarse, activarse y mantenerse sin mezclar credenciales.

Extracción de CV

El usuario sube un PDF, n8n extrae el texto, un agente identifica ocho campos clave y Google Sheets registra una fila.

Promomail automático

Un formulario recoge correo y tema de interés. Gmail envía en automático el contenido solicitado con HTML personalizado.

Chatbot público

La página carga el widget de chat de n8n y conversa con un agente que explica servicios, formularios y próximos pasos.

Flujo de atención

La navegación principal queda visible desde el primer pantallazo y el chatbot se integra como parte usable de la landing.

1

Visitante

Ingresa desde GitHub Pages, revisa la propuesta y abre el chat o un formulario.

2

n8n

Recibe el mensaje o registro mediante Chat Trigger y Form Trigger.

3

Agente

Responde consultas o extrae datos del CV con reglas claras y campos definidos.

4

Google

Sheets almacena datos de CV y Gmail envía el promomail solicitado.

Ocho campos del CV

La hoja de cálculo guarda únicamente la información esencial para revisar candidatos.

CampoDescripción
nombre_completoNombre y apellidos indicados en el CV.
correo_electronicoCorreo de contacto explícito y validado.
telefonoTeléfono como texto, conservando prefijos.
ubicacionCiudad, región o país indicado.
perfil_profesionalResumen breve del perfil o profesión.
formacion_academicaEstudios, institución y fechas relevantes.
experiencia_laboralCargos, empleadores, fechas y funciones.
habilidadesHerramientas, conocimientos, idiomas y capacidades.

Conexión final

Cuando los workflows estén activos, se reemplazan las tres URLs en el archivo de configuración. No se colocan credenciales en la web.

Formulario promomail Formulario CV
window.PROJECT_CONFIG = { N8N_CHAT_WEBHOOK_URL: "https://tu-n8n/webhook/...", CV_FORM_URL: "https://tu-n8n/form/registro-cv", PROMO_FORM_URL: "https://tu-n8n/form/solicitar-informacion" };
